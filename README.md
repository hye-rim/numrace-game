# 숫자 레이스 🏁

흩어진 **1~25** 를 **1부터 순서대로** 먼저 끝까지 누르는 속도 대결. 컴퓨터와 하거나 방 코드로 친구와 실시간으로 겨룬다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **규칙**: 5x5 판에 1~25 가 무작위로 섞여 있다. 두 사람이 **같은 판**을 보고 각자 1, 2, 3 … 순서로 눌러 **25 를 먼저 누르면 이긴다**. 서로 방해할 수 없고, 상대가 어디까지 갔는지는 위쪽 막대로 보인다
- **틀리면**: 다음 숫자가 아닌 칸을 누르면 **0.6초 동안 멈춘다** (그동안 누른 건 안 먹힌다). 이미 누른 숫자를 또 눌러도 벌은 없다
- **시간**: 한 판 90초. 못 끝내면 **더 멀리 간 쪽이 이기고**, 같은 곳이면 무승부. 시작 전에 3-2-1 을 센다 (그동안 판은 가려져 있다)
- **컴퓨터**: 숫자 하나를 찾는 데 쉬움은 평균 1.8초(±0.5), 어려움은 1.1초(±0.3)가 걸린다. 틀리지는 않는다. 사람이 이기면 최고 기록(걸린 시간)을 저장한다. 튜토리얼에서는 컴퓨터가 12배 느리다
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 판 더(판을 새로 섞음) · 기권·이탈은 패배. 누르기는 `tap` 하나(`{cell}`)로 오고, **숫자가 맞는지 · 잠금 · 승패는 서버가 판정**한다. 판의 숫자 배치는 시작 신호(3-2-1 뒤) 이후에야 보내므로 미리 볼 수 없고, 한 사람이 25ms 안에 보내는 누르기는 무시한다. 인터넷 지연이 판정에 영향을 줄 수 있다 (먼저 서버에 도착한 쪽이 이김)
- 컴퓨터를 이긴 횟수는 `numraceWins` (로비 표시용), 최고 기록은 `numraceBestMs`, 온라인 전적은 `numraceOnline`

규칙·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭·판정은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(판이 1~25 를 한 번씩 담음, 틀림 잠금, 이미 누른 숫자 무벌, 먼저 25 가 승리, 잘못된 입력 무시, 시간 종료 승패, 컴퓨터 속도), `test/server.test.js`(서버를 띄워 매칭 · 카운트다운 동안 판 비공개 · 같은 판 · 진행 상황 공유 · 틀림 잠금 · 잘못된 입력 · 25 완주 · 시간 종료 · 기권 · 한 판 더 · 이탈 · 재접속).
