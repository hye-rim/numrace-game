# 숫자 레이스 🏁

흩어진 **1~25** 를 **1부터 순서대로** 빨리 누르는 게임. **혼자 하기**(단계별 제한 시간 · 남은 시간만큼 점수 · 콤보)와 방 코드로 친구와 하는 **온라인 대전**(먼저 끝내기). [작은 오락실](https://github.com/hye-rim/smallgame)

- **규칙**: 5x5 판에 1~25 가 무작위로 섞여 있다. 두 사람이 **같은 판**을 보고 각자 1, 2, 3 … 순서로 눌러 **25 를 먼저 누르면 이긴다**. 서로 방해할 수 없고, 상대가 어디까지 갔는지는 위쪽 막대로 보인다
- **틀리면**: 다음 숫자가 아닌 칸을 누르면 **0.6초 동안 멈춘다** (그동안 누른 건 안 먹힌다). 이미 누른 숫자를 또 눌러도 벌은 없다
- **시간**: 한 판 90초. 못 끝내면 **더 멀리 간 쪽이 이기고**, 같은 곳이면 무승부. 시작 전에 3-2-1 을 센다 (그동안 판은 가려져 있다)
- **혼자 하기(기록 도전)**: 10단계, 단계마다 제한 시간 60·55·50·46·42·38·35·32·29·26초(`STAGE_SEC`). 1~25 를 다 누르면 단계 클리어, **남은 시간 1초 = 100점**(`clearBonus`). 숫자 하나는 10점이고 **콤보**(안 틀리고 이어서 맞힌 수)가 5개 쌓일 때마다 배수가 1씩 올라 **최대 x5**(`comboMult`). 틀리면 0.6초 멈추고 콤보가 끊긴다. 점수와 콤보는 다음 단계로 이어지고, 시간이 끝나면 거기서 끝난다. 시작 때만 3-2-1, 다음 단계는 "N단계"를 잠깐 보여 준다. 컴퓨터 상대는 없다(예전 컴퓨터 대전은 뺌)
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 판 더(판을 새로 섞음) · 기권·이탈은 패배. 누르기는 `tap` 하나(`{cell}`)로 오고, **숫자가 맞는지 · 잠금 · 승패는 서버가 판정**한다. 판의 숫자 배치는 시작 신호(3-2-1 뒤) 이후에야 보내므로 미리 볼 수 없고, 한 사람이 25ms 안에 보내는 누르기는 무시한다. 인터넷 지연이 판정에 영향을 줄 수 있다 (먼저 서버에 도착한 쪽이 이김)
- 혼자 하기 최고 점수는 `numraceBest`(로비 표시용), 최고 단계는 `numraceBestStage`, 온라인 전적은 `numraceOnline`

규칙은 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭·판정은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(판이 1~25 를 한 번씩 담음, 틀림 잠금, 이미 누른 숫자 무벌, 먼저 25 가 승리, 잘못된 입력 무시, 시간 종료 승패, 컴퓨터 속도), `test/server.test.js`(서버를 띄워 매칭 · 카운트다운 동안 판 비공개 · 같은 판 · 진행 상황 공유 · 틀림 잠금 · 잘못된 입력 · 25 완주 · 시간 종료 · 기권 · 한 판 더 · 이탈 · 재접속).
